# ridgefield

Estadistica descriptiva sobre listas de numeros.

## Uso

```python
from estadistica import media, resumen

media([1, 2, 3])       # 2.0
resumen([1, 2, 3])     # {"n": 3, "media": 2.0, ...}
```
